# 🎮 Taş Kağıt Makas Oyunu

Web geliştirme öğrenme sürecimin ilk projesi. 
HTML, CSS ve JavaScript temellerini pekiştirmek için geliştirdim.

## 🎯 Projenin Amacı
Bu proje benim **ilk web projem.** Amacım:
- HTML, CSS, JavaScript'in nasıl birlikte çalıştığını görmek
- Tarayıcıda bir oyunun nasıl çalıştığını anlamak
- GitHub ve Git kullanmayı öğrenmek
- Hata ayıklama pratiği yapmak

## 🛠️ Kullanılan Teknolojiler
- HTML5
- CSS3 (Glassmorphism tasarım)
- Vanilla JavaScript
- Web Audio API

## 🚀 Nasıl Çalıştırılır?
`index.html` dosyasını tarayıcıda aç, oyun başlar.

Canlı demo: [Buradan oyna](https://kivanc5252.github.io/tas-kagit-makas)
